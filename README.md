# 📡 WebSocket Notification System

## 📌 Deskripsi
Project ini merupakan implementasi sederhana sistem notifikasi real-time menggunakan teknologi WebSocket. Sistem ini memungkinkan server mengirim pesan langsung ke client tanpa perlu melakukan refresh halaman, sehingga lebih cepat dan efisien dibandingkan metode HTTP konvensional.

---

## 🎯 Tujuan
- Memahami konsep komunikasi real-time  
- Menerapkan WebSocket dalam sistem notifikasi  
- Membandingkan WebSocket dengan HTTP (polling)  
- Mengimplementasikan sistem sederhana untuk eksperimen  

---

## ⚙️ Teknologi yang Digunakan
- Node.js  
- Express.js  
- WebSocket (ws)  
- HTML, CSS, JavaScript  

---

## 🧩 Fitur
- Notifikasi real-time tanpa refresh  
- Server dapat mengirim pesan ke banyak client  
- Implementasi sederhana dan mudah dipahami  

---

## 🚀 Cara Menjalankan Project

### 1. Clone Repository
```bash
git clone https://github.com/dobel123/websocket-notifiation.git
cd websocket-notifiation
```

## install dependency
```
npm install
```

## jalankan server
```
node server.js
```

## buka di browser
```
index.html
```

## kirim notifikasi
```
http://localhost:3000/send
```
